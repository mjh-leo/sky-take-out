# Day16 - 导出Excel报表

## 一、Apache POI

**Apache POI 是处理 Microsoft Office 各种文件格式的开源项目**，可以在 Java 程序中读写 Office 文件，一般用于操作 Excel。

**应用场景：**
- 银行网银系统导出交易明细
- 各种业务系统导出 Excel 报表
- 批量导入业务数据

业务系统里，用户要的报表不能只停留在页面上，要能下载成 Excel 文件，方便存档、分析、发给别人 → 所以后端要用 POI 生成 Excel。

**POI 核心概念：**

| 对象 | 对应 Excel | 层级 |
|------|-----------|------|
| Workbook | 整个 Excel 文件 | 最外层 |
| Sheet | 一个工作表 | 文件 → 表 |
| Row | 一行 | 表 → 行 |
| Cell | 一个单元格 | 行 → 格 |


## 二、导出运营数据 Excel 报表

### 1. 业务规则

- 导出 Excel 形式的报表文件
- 导出**最近30天**的运营数据

### 2. 接口设计

```
Path: /admin/report/export
Method: GET
```

- **不需要请求参数**：业务是"导出最近30天"，日期范围后端自己算（今天往前推30天）
- **不需要返回数据**：接口没有返回数据，因为报表导出本质上是文件下载——服务端通过输出流把 Excel 文件直接写给客户端浏览器，不是返回 JSON。
### 3. 代码开发

**实现步骤：**
1. 设计 Excel 模板文件
2. 查询近30天的运营数据
3. 将查询到的运营数据写入模板文件
4. 通过输出流将 Excel 文件下载到客户端浏览器

**完整流程：**

```
查数据库 → 拿到近30天营业数据（营业额/订单/用户/销量TOP10）
    ↓
从项目资源目录读取模板文件（.xlsx）
    ↓
用模板创建新的 Excel（复用格式，不从头画）
    ↓
getRow / getCell 定位单元格，写入数据
    ↓
把填好的 Excel 写入 response 输出流
    ↓
浏览器自动下载文件
```
### 4. 我踩的两个坑

坑1：模板文件名忘了后缀 `.xlsx`，资源目录的模板文件路径写错，POI 找不到文件

坑2：`getRow(4)` 写成了 `createRow(4)`

- `createRow` 是**新建**一行（会覆盖/报错），`getRow` 是**取已有**行
- 模板文件的行已经设计好了，直接 `getRow` 拿出来填数据
---
## ⚠️ 避坑 Tips

### 1. POI 操作 Excel 的坑
- **模板路径要写全后缀**。`template.xlsx` 少写 `.xlsx` 直接报错。
- **getRow 是取，createRow 是建**。模板里已有的行用 getRow；要新增内容才用 createRow
- **Workbook 用完要关**。`workbook.close()`，不关会占内存，导出多了会 OOM

### 2. 文件下载的坑
- **响应头要设置对**：
  - `Content-Type: application/vnd.ms-excel`
  - `Content-Disposition: attachment; filename=xxx.xlsx`（attachment 表示下载，inline 是预览）
- **文件名中文乱码**。中文文件名要 URL 编码，不然浏览器下载下来文件名是乱码
- **输出流用 BufferedOutputStream 包一下**，大数据量性能更好
- **写完要 flush**，确保数据全部写出

## 🎯 面试高频题

### Q1：怎么实现导出 Excel 报表？

> **回答框架：**
> 1. **技术**：Apache POI 操作 Excel
> 2. **流程**：
>    - 查数据库拿到统计数据
>    - 读模板文件，创建新的 Excel
>    - 获取行和单元格，写入数据
>    - 写入 response 输出流，浏览器下载
> 3. **为什么用模板**：格式（标题/表头/列宽）提前设计好，代码只填数据
> 4. **注意点**：响应头 Content-Type 和 Content-Disposition 设置，中文文件名编码
>
> **面试话术**："导出报表用 Apache POI。先查需求时间范围内的运营数据，从资源目录读模板文件创建 Excel，用 getRow 拿到指定行填充数据，最后写入 response 输出流，设置好 Content-Disposition 让浏览器下载。用模板是为了复用格式，代码只负责填数据。"
